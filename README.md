# Ergonomía Multimétodo

Plataforma digital para análisis y gestión ergonómica multimétodo, adaptada al contexto profesional argentino.

## Principio rector

La IA propone; el algoritmo calcula; el profesional valida, interpreta y decide.

## Flujo

CASO -> TAREA -> CONTEXTO -> EVIDENCIA -> OBSERVACIÓN -> FACTORES 886 -> VALIDACIÓN PROFESIONAL -> DATOS CONFIRMADOS -> MOTOR DE APLICABILIDAD -> MÉTODOS SUGERIDOS -> ELECCIÓN PROFESIONAL -> CÁLCULO -> RESULTADO -> MEJORA -> SEGUIMIENTO

## Métodos

- RULA
- REBA
- NIOSH
- Futuros módulos

Los métodos mantienen variables, reglas y resultados independientes.

## Responsabilidad profesional

La IA no toma decisiones profesionales. Las estimaciones visuales no se presentan como mediciones instrumentales. Los datos que alimentan cálculos deben ser confirmados por el profesional.

## Estado

El proyecto evoluciona desde un calculador RULA hacia una plataforma profesional multimétodo con trazabilidad y validación humana.
